# rawboot — загрузчик Allwinner T113-S3

Загрузчик второй ступени, написанный на Rust для Allwinner T113-S3 (ARMv7-A, два ядра Cortex-A7),
портированный из `szemzoa/awboot`, но идиоматичный Rust. Он инициализирует SoC, загружает
собственный образ прошивки и передаёт управление.

## Язык

**BROM**:
Встроенный в кристалл Allwinner ROM первой ступени; он загружает и проверяет образ eGON с SD
(сектор 16, резервный 256), SPI-флеша или через USB FEL.

**FEL**:
Режим восстановления/загрузки Allwinner по USB; хостовый инструмент загружает образ в SRAM/DRAM и
запускает его.

**FEL transport** (крейт `rawboot-fel`):
Наша хостовая реализация USB-протокола FEL BROM: обнаружение устройства, версия и chip ID, а также
чтение/запись/исполнение памяти, с CLI для ручного bring-up. `xfel` остаётся внешним инструментом
для HIL-скрипта.
_Избегать_: FEL library, xfel clone

**FEL mailbox**:
Блок из четырёх слов в SRAM режима FEL (магия `RBFM`, адрес образа payload, размер образа,
указатель на аргумент), который хост записывает перед запуском loader через FEL. При наличии loader
загружает загруженный образ payload вместо чтения `payload.bin` с SD-карты.

**DDR-init stub** (образ `rawboot-ddr-init`):
Небольшая вызываемая из FEL программа, загружаемая в SRAM по адресу `0x00028000`, которая
инициализирует DRAM общим драйвером, оставляет свой результат в SRAM и возвращается в BROM, чтобы
FEL оставался доступен. Не несёт заголовка eGON и не является loader второй ступени (ADR-0013).

**flasher** (крейт `rawboot-flasher`):
Вызываемая из FEL программа, слинкованная в DRAM по адресу `0x40010000`, которая читает flash job,
выполняет его, записывает flash status и возвращается в BROM. Отвечает на задание `NOOP` и на
задание `FLASH_COMMAND_FLASH_SD`, которое записывает подготовленные файлы payload и loader на карту.
Не несёт заголовка eGON.

**flash job/status**:
Контрольные по сумме, версионированные блоки `FlashJob`/`FlashStatus` по фиксированным адресам DRAM,
которыми обмениваются хост и flasher (`RBFJ`/`RBFS`, магия, версия, размер, контрольная сумма,
последовательность, шаг, результат).

**flash plan**:
Контрольный по сумме блок `FlashPlan` (`RBFP`) по адресу `0x40000200`, задающий длины и контрольные
суммы подготовленного образа payload, необязательного содержимого `boot.cfg` и запечатанного SD/SPI
loader. Хост записывает его перед выполнением задания `FLASH_COMMAND_FLASH_SD`; flasher проверяет
его и подготовленные области.

**FEL flash** (`cargo xtask fel-flash`):
Путь обновления в самой плате: собрать или переиспользовать образы loader, payload и flasher,
проверить запечатанный SD loader, подготовить всё в DRAM через FEL и позволить flasher записать
существующий корень FAT и сектор 16, не трогая MBR (ADR-0014).

**eGON**:
Заголовок загрузочного образа Allwinner (магия `eGON.BT0`, контрольная сумма seed `0x5F0A6C39`),
добавляемый в начало бинарника ступени, чтобы BROM его принял.

**loader** (крейт `rawboot`):
Наша программа второй ступени: инициализирует SoC, читает payload из накопителя и выполняет handoff.
_Избегать_: приложение, SPL

**runtime** (крейт `rawboot-rt`):
Слой запуска, который размещает заголовок eGON, задаёт стек, обнуляет BSS/копирует данные и вызывает
`main` у loader.
_Избегать_: фреймворк, ОС, HAL

**`sunxi-pl`** (платформенный слой):
Общий аппаратный слой для loader, `rawboot-rt` и payload: MMIO, GPIO, таймер. Подобен CMSIS, не
содержит кода запуска.
_Избегать_: HAL, драйверный крейт, платформа

**`sunxi-drivers`** (драйверный крейт):
Драйверы Allwinner T113-S3 поверх `sunxi-pl`: clock/CCU, DRAM, UART, SDHCI, SD/MMC и FAT-адаптер
(только для чтения в loader, для чтения и записи в flasher и хостовых тестах). Общий для loader и
flasher; не содержит кода запуска, заголовка eGON, linker script или глобального аллокатора и
сообщает о прогрессе через трейт `Console`, поэтому не зависит от `print!` loader.
_Избегать_: HAL, BSP, платформенный слой

**payload**:
Образ, который загружает loader, — собственная прошивка пользователя (возможно, микроядро), включая
тривиальный тестовый образ вроде цикла мигания. Не Linux.
_Избегать_: ядро, zImage

**image header**:
Фиксированный заголовок `#[repr(C)]` в начале образа payload (магия, версия, флаги, точка входа,
адрес загрузки, размер, контрольная сумма), который разбирает loader.

**SD boot prefix**:
Собранный на хосте `target/rawboot-sd-mbr.img`: MBR, указывающий на существующий FAT-раздел, плюс
запечатанный SD/SPI loader в секторе 16, длиной ровно до начала раздела (1 MiB по умолчанию). Не
содержит тома FAT и не содержит payload и записывается на карту через `dd conv=notrunc`;
форматирование и `payload.bin` остаются на разделе.
_Избегать_: SD image, full image

**BootInfo**:
Версионированный дескриптор `#[repr(C)]`, который loader размещает в DRAM и передаёт payload в `r0`
при handoff.

**boot.cfg**:
Необязательный файл на томе FAT, содержимое которого loader копирует в DRAM как строку с
завершающим NUL и предоставляет через `BootInfo.args`; при отсутствии указатель `args` равен null.

**handoff**:
Передача управления от loader к payload в определённом состоянии CPU и регистров.

**DRAM init**:
Инициализация контроллера DDR3 T113, без которой DRAM непригодна.

**upstream**:
C-проект `szemzoa/awboot`, из которого портирован `rawboot`; поведение, на которое мы ориентируемся.
_Избегать_: оригинал, референс, вендор

**parity**:
Поведенческая эквивалентность с upstream — тот же порядок шагов, константы, ветвления и таблицы —
достигнутая нашим собственным выражением на Rust.
_Избегать_: порт, совпадение, точность

**regs**:
Именованные константы и структуры регистров MMIO, перенесённые из даташита T113 и awboot.
