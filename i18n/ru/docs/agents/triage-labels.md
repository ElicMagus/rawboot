# Метки триажа

Навыки говорят в терминах ролей триажа: две роли **category** и пять ролей **state**. Этот файл сопоставляет эти роли с фактическими строками меток, используемыми в трекере issue этого репозитория.

## Роли category

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                   |
| ------------------------- | --------------------- | -------------------------- |
| `bug`                     | `bugfix`              | Что-то сломано             |
| `enhancement`             | `feature`             | Новая возможность или улучшение |

## Роли state

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                      |
| ------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить эту issue           |
| `needs-info`              | `needs-info`          | Ожидание дополнительной информации от автора  |
| `ready-for-agent`         | `ready-for-agent`     | Полностью специфицирована, готова для AFK-агента |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                  |
| `wontfix`                 | `wontfix`             | Не будет обработана                           |

Когда навык упоминает роль (например, «применить метку триажа, готовую для AFK»), используйте соответствующую строку метки из этой таблицы.
