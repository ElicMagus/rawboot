# Передавать управление в состоянии CPU от BROM; без перехода TrustZone и PSCI

Payload работает на CPU0 в том состоянии, в каком его оставил BROM — ARMv7-A,
secure, MMU и кэши выключены, IRQ замаскированы — тогда как CPU1 остаётся
припаркованным, и подъём SMP принадлежит payload. Монитор secure→non-secure из
оригинала на C (`nonsec_virt.S`, `psci_vectors.S`, перемещение secure-секции)
существует только чтобы обслуживать non-secure ОС через SMC; самодостаточному
микроядру он не нужен, поэтому мы отбрасываем всю эту подсистему и возвращаем её
только по требованию.
