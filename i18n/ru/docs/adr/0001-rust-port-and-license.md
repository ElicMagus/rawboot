# Портировать awboot на 100% Rust под CC-BY-4.0

`szemzoa/awboot` — это C-загрузчик для T113-S3; наш преемник — чистое
переписывание на 100% Rust (без C, даже для DRAM init, который уже на Rust). Мы
переносим из awboot и даташита только *факты* — адреса, смещения регистров,
позиции битов, имена констант — а поведение пишем сами, идиоматично (собственные
типы, трейты, `&raw`-аксессоры). Порт выпускается под `CC-BY-4.0` (SPDX
`CC-BY-4.0`), что разрешает повторное использование и модификацию, но требует
атрибуции. Мы намеренно избегаем копирования тел кода из файлов awboot под
GPL-2.0+/GPL-2.0-only и без лицензии, условия которых наша лицензия не сделала
бы безопасными.
