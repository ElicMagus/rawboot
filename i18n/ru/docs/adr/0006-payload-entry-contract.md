# Контракт входа payload

При handoff loader входит в payload в состоянии ARM, в режиме Supervisor (SVC),
с выключенными MMU и кэшами и замаскированными IRQ/FIQ; `r0` содержит адрес
`BootInfo`, а `r1` равен нулю. Loader указывает `SP` на зарезервированный стек в
DRAM, чтобы минимальный payload (например, тестовый образ мигания) стартовал без
собственного startup-кода; payload владеет своей картой памяти и может
переместить `SP`. Адрес загрузки payload берётся из заголовка его образа, по
умолчанию `0x42000000`. Именно этот фиксированный, документированный контракт
позволяет тестовому образу мигания доказать всю цепочку (SD → FAT → DRAM →
handoff) от начала до конца.
