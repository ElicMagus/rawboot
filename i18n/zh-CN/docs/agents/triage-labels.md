# Triage 标签

这些 skills 使用 triage 角色来描述：两个**类别**角色和五个**状态**角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

## 类别角色

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义         |
| -------------------------- | --------------------- | ------------ |
| `bug`                      | `bugfix`              | 某个东西坏了 |
| `enhancement`              | `feature`             | 新特性或改进 |

## 状态角色

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                                     |
| -------------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`        | 维护者需要评估此 issue                   |
| `needs-info`               | `needs-info`          | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`     | 已完全指定，可供 AFK agent 使用          |
| `ready-for-human`          | `ready-for-human`     | 需要人工实现                             |
| `wontfix`                  | `wontfix`             | 不会处理                                 |

当某个 skill 提到某个角色（例如 "apply the AFK-ready triage label"），使用此表中对应的标签字符串。
